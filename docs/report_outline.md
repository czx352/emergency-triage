# 课程设计报告大纲

## 题目

基于双塔融合与序数回归的急诊分诊分级模型——补齐开源医疗 OS 的分诊 AI 服务

## 一、绪论（2 页）

1.1 背景：急诊分诊决定抢救资源分配，错误分级的代价不对称
1.2 问题来源：开源医疗 OS「JLAIharnessos」宣称具备分诊 AI，实际为硬编码常量（附源码截图与链接）
1.3 本文工作：一个可训练、可评估、可服务的真实分诊模型；三项设计（序数损失、代价敏感、门控融合）
1.4 贡献列表（3 条，务必具体、可验证）

## 二、相关工作（2 页）

2.1 急诊分诊与 ESI 分级体系
2.2 表格数据深度模型（MLP / FT-Transformer）与树模型基线
2.3 临床文本预训练模型（Bio_ClinicalBERT、PubMedBERT）
2.4 序数回归（CORAL、ordinal binary decomposition）与代价敏感学习

## 三、方法（4-5 页）

3.1 任务定义：输入 x = (主诉, 生命体征, 人口学)，输出 y ∈ {1..5}，有序
3.2 文本塔：临床预训练模型 + 掩码均值池化（附结构图）
3.3 结构化塔：标准化 + 缺失数量特征 + 两层 MLP
3.4 门控融合：g = σ(W[z_t; z_v])，z = g ⊙ z_t ⊕ z_v
3.5 输出头与损失
   - CORAL：K-1 个累积 logit，target_k = 1[y > k]
   - 代价敏感：L = NLL + λ·E[cost]，给出推导
3.6 训练细节：AdamW、梯度裁剪、按验证集 QWK 早停

## 四、实验（5-6 页）

4.2 划分：按患者划分，说明为什么不能按记录随机划分（泄漏）

4.4 主结果表：结构化基线 / 文本基线 / 简单拼接 / 双塔+CORAL（均值 ± 95% CI）
4.5 消融表：门控 vs 拼接；CORAL vs CE；是否代价敏感；hash vs 预训练文本塔
4.6 混淆矩阵与错误分析：危重降级集中在哪几类主诉（给 2-3 个真实错例）

## 创新点的写法（避免空话）

不要写“提出了一个创新的模型”。写具体：

1. 把 ESI 的有序结构显式建模：CORAL 输出 K-1 累积概率，概率分布天然单调，避免“1 级概率低于 2 级”的非法输出；
2. 损失函数直接对齐临床风险：以代价矩阵最小化期望代价，使危重降级（ESI1→4，代价 8）比轻度高估（代价 1）受到 8 倍惩罚；
3. 评估口径从“分得准”转为“分得安全”：以危重降级率为主指标，而非准确率。

## 答辩预设问题

1. 为什么不用准确率？——类别不平衡 + 错误代价不对称，答不出就说明没理解任务。
2. 你的模型比 LightGBM 好在哪？——必须给出消融数据，不能只讲结构。
3. 合成数据的结论能信吗？——承认局限，说明已用真实数据管线验证，指标仅证明方法有效。
4. 危重样本只有 2%，怎么处理？——类别权重、代价敏感、分层划分、重点看召回。
5. 医生会不会被误导？——强调辅助定位、概率输出、不替代判断、以及 Top-2 兜底建议。
